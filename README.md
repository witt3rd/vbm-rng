# vbm-rng has moved

**This repository is archived (read-only).** The library now lives in the VBM family repository:

> **https://github.com/witt3rd/vbm/tree/main/lib/vbm-rng**

* **History:** all of this repository's history is in the family repository (`git log lib/vbm-rng`, `git blame` follow it).
* **Releases:** the release made here, `v0.1.0`, stays here with its signature. The same tree is released there as `vbm-rng/v0.1.0` (signed by the same key; its `tree_sha256` is identical). New releases are tagged `vbm-rng/vX.Y.Z` in the family repository.
* **Issues and changes:** open them in the family repository.
* **Pins:** a pin at `v0.1.0` of this repository keeps verifying (the files are unchanged); re-point it with `land-pin vendor vbm-rng https://github.com/witt3rd/vbm vbm-rng/v0.1.0` and the vendored files come out byte for byte as they were.
